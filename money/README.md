VORTEX Money: a personal-finance app that stress-tests your savings plan against crash scenarios generated by the
VORTEX-AI CG-NSDE model, with goal planning, diversification checks and a mutual-fund X-ray (public AMFI NAVs via
mfapi.in).

Educational student project (Fr. CRCE, Mumbai). Not investment advice. Accounts on this demo server may be reset.
